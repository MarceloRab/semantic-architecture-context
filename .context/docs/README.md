# Context Docs Index - semantic-architecture-context

Use this folder only for stable reference docs that are not suitable for `active_context.md`.

## Rules
- Keep docs factual and concise.
- Add `last_verified`, `owner`, `source_of_truth`, and `expiry_days` in long-lived docs.
- Archive stale docs in `.context/archive/` instead of keeping contradictory versions.
- For large projects, keep deep architecture details inside `.context/docs/architecture_drawers/*`.
- Keep `PROJECT_ARCHITECTURE.md` compact and use it as a router to the relevant drawer.
