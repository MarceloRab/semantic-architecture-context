# Archive Policy

Archive content that no longer drives immediate execution:

- old task logs
- outdated snapshots
- superseded architecture drafts

## Trigger conditions
- Not updated for 30+ days
- Replaced by canonical file elsewhere
- Causes repeated confusion or contradictory guidance

## Rules
- Archive path: `<repo>/.context/archive/YYYY-MM/`
- Keep a one-line pointer in active docs when moving content.
- Do not delete history unless explicitly requested.
